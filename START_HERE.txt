📤 EXCEL UPLOAD
═══════════════════════════════════════════════════════════════════════════════

Your Excel file should have these columns (in this order):

1.  Sr No.
2.  Proposal Number
3.  Proposal Code
4.  Transaction Date
5.  Service Name
6.  Owner Name
7.  Site Address
8.  Pending By
9.  Designation
10. Application Received Date
11. Days

Date format: DD-MM-YYYY (e.g., 22-08-2025)
File format: .xlsx, .xls, or .csv
Max size: 10 MB

See EXCEL_FORMAT_GUIDE.md for detailed specifications.
